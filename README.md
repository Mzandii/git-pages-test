# My GitHub Pages Static Site

This is a static website hosted on GitHub Pages with HTML, CSS, and JavaScript.

## Features

- Responsive design
- Interactive JavaScript functionality
- Modern CSS styling
- Mobile-friendly layout

## How to Use

1. Click the buttons to see JavaScript in action
2. Enter your name in the input field
3. Use the counter to increment/decrement values
4. Click "Load Data" to see dynamic content

## Setup Instructions for GitHub Pages

1. Create a new repository on GitHub
2. Upload these files to your repository:
   - index.html
   - style.css
   - script.js
3. Go to repository Settings → Pages
4. Select "main" branch as source
5. Your site will be published at: `https://[username].github.io/[repository-name]/`
